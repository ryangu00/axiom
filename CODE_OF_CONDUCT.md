# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, critique work not people. Harassment
of any kind is not tolerated. Maintainers may remove, edit, or reject
contributions and comments that violate this standard.

Report unacceptable behavior via the repository's private security/advisory
channel (see [SECURITY.md](SECURITY.md)); reports are handled confidentially.
